# Test Plan

The CSV in this folder consolidates the 16 test cases in the original Group 05 coursework workbook into one row per test case.

Columns:
- TC ID
- Description
- Steps
- Expected Behavior
- Recorded Status
- Execution Observation

The recorded PASS / FAIL statuses and observations are historical evidence from the coursework execution dated 20 November 2025. They are not current re-test results. Several failures were expected-versus-actual message differences; TC12 and TC13 were blocked by the mailbox/application error described in the original workbook.
